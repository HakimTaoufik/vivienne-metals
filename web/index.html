SIMULATION CHRONOLOGIQUE

Tester sur l’historique

Le test attend au moins 32 jours de prix réels. Aucun historique n’est inventé.

Ce qui déclenche un signal

Le modèle compare la prime actuelle à la médiane de la même boutique sur les jours précédents. L’écart est normalisé par la déviation absolue médiane (MAD), avec un plancher de 0,25 point. Un achat doit aussi passer les limites de spread, de budget, de quantité et de marge après frais. Une vente doit offrir une prime de rachat anormalement haute.

Le score n’est pas une probabilité de gain. Les données commencent à la première collecte. Les emails suivent les seuils enregistrés dans le dépôt ; les suggestions liées à vos avoirs restent locales.
